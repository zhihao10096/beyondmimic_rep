# 采样算法与接口规范

本文件补充02契约，用于减少后续实现的索引、尺度与梯度错误。DDPM posterior公式是标准数学；具体cosine日程、mask接口和guidance离散化是本项目工程选择，不声称还原了未公开的作者代码。

## 1. clean level和标准 DDPM

用扩散噪声步k，与物理时间t明确区分。K20；`alpha_bar[0]=1`；其余k1..20为cosine累计信号衰减，终点接近0。定义：

```text
alpha[k] = alpha_bar[k] / alpha_bar[k-1]
beta[k] = 1 - alpha[k]
q_sample(x0,k,eps) = sqrt(alpha_bar[k])*x0 + sqrt(1-alpha_bar[k])*eps
```

coefficients建议fp64生成、保存后训练转换fp32。cosine末端alpha_bar用eps避免除零，同时保证terminal sqrt(alpha_bar)很小；选定floor和hash写checkpoint。未知输入从standard Gaussian开始，已知feature使用真正clean数值。

x0 denoiser输出`x0_hat`。标准posterior：

```text
c1[k] = beta[k] * sqrt(alpha_bar[k-1]) / (1-alpha_bar[k])
c2[k] = (1-alpha_bar[k-1]) * sqrt(alpha[k]) / (1-alpha_bar[k])
posterior_mean = c1[k]*x0_hat + c2[k]*x_k
posterior_variance[k] = beta[k] * (1-alpha_bar[k-1]) / (1-alpha_bar[k])
x_[k-1] = posterior_mean + sqrt(posterior_variance[k])*eps
```

k1时posterior_variance为0，直接到x0；k0是已知clean，不参加除`1-alpha_bar[0]`的操作。对state/z各自k按feature广播系数；known feature只clamp，不加noise。

如果使用epsilon表示，明确转换：

```text
eps_hat = (x_k - sqrt(alpha_bar[k])*x0_hat) / sqrt(1-alpha_bar[k])
```

不能把x0_hat当epsilon直接套reverse公式。k0不计算上式。

DDIM对照eta0：`x_prev=sqrt(alpha_bar[k-1])*x0_hat+sqrt(1-alpha_bar[k-1])*eps_hat`。这个公式与DDPM后验不同；把两者分别命名、验证、记录。

## 2. 网络和关键mask接口

拟议纯PyTorch签名：

```python
denoiser(
    noisy_tokens,        # [B,21,195]：projected state + normalized latent
    noise_levels,       # [B,21,2]，state/z各一个k，值0..20
    known_feature_mask, # [B,21,195] bool；可嵌入mask，工程选择
    valid_time_mask,    # [B,21] bool；startup padding和loss有效性
) -> predicted_clean_tokens  # [B,21,195]
```

具体token维度从schema推导，不散落硬编码195。known feature mask可经线性projection加到embedding，避免部分keyframe与未知feature语义不清；同训练/推理路径一致。padding不能用未来真实state填补。

全部state observed时其k_state=0；全部z observed时k_z=0；future部分state keyframe约束下k_state仍标未知部分noise等级，known channels独立clamp并通过mask说明，不能把整个state设k0误表示全干净。

训练样本：真实clean窗口→逐token随机state/z k→q_sample→按选择的known mask覆盖→预测clean→只在valid/目标loss mask上计算MSE，分state/latent并按有效维数记录。加入与推理相同的history/current mask情形；futurekeyframe训练比例工程选定，默认先少量并记录。

state/latent分组loss各mean后等权相加与全feature维度平均的权重不同，必须冻结一种。**本项目主线对valid且未被known mask固定的目标feature整体平均，known feature不计训练loss，另外报告state/latent分组mean；不能同config训练时偷偷切换。** emphasis通过P影响state目标，归一化顺序见02。分组等权只作为独立消融。

## 3. 一次 guided sampling 的明确流程

```text
输入：raw actual history，current actual state，past executed z，task目标
1. 用current raw pose/yaw重新transform整个实际history。
2. state normalize→P；past z按latent stats normalize。
3. 构造21-frame template与known mask。
   past state/z和current state为known，current z为unknown。
4. unknown token初始化Gaussian，known值clamp。
5. for k=20..1:
      x = detach(current_sample).requires_grad_(guidance_enabled)
      levels = unknown field k，fully known field 0
      pred_x0 = denoiser(x,levels,masks)
      pred_x0_known = clamp(pred_x0,known_values)
      mean = posterior(pred_x0_known,x,levels)
      if guidance_enabled:
          physical = inverse_projection_and_state_normalization(pred_x0_known)
          world_prediction = restore_root_and_body_world(physical,current_context)
          cost = weighted_task_cost(world_prediction)
          grad = d(cost.sum())/d(x)
          grad[known_mask] = 0
          可选grad norm clip，记录clip率与每levelnorm
          mean = mean - guidance_weight[k] * posterior_variance[k] * grad
      sample = mean + standard_noise*posterior_std[k]
      sample = clamp(sample,known_values)
      detach sample后进下一级
6. current_z = inverse_latent_normalization(sample[:,4,state_dim:])
7. action = frozen_vae_decoder(current_z,latest_actual_proprio)
8. actual physics step；记录当前实际state/z/action和返回transition。
```

guidance不训练weights，`requires_grad`只针对sample；freeze model params减少内存。guidance路径不得在inference_mode环境创建tensor后直接反传。known约束每level严格恢复，cost只包含可调整未来维度；当前固定state项仅供日志。

如果工程实验用另一种guidance（例如修改noisy input后重新denoise），按sampler_type另存，不改动此主线公式。不同scale下应重新验证finite differences与真实执行收益。

gradient可能在current z上为0，因后验state/z模型未学到相容关系。不能以“cost下降”掩盖此情况，应同时报告current z/action改变量、未来state与实际physics响应，先做causal consistency诊断。

## 4. 物理decode接口

```python
decode_physical_predictions(
    projected_states,  # [B,21,Ds_projected]
    state_stats,
    projection_pinv,
    current_context,   # p_world_t, yaw_rotation_t, v_world_t
) -> {
    root_pos_w, root_rot_w, root_lin_vel_w, root_ang_vel_w,
    body_pos_w, body_lin_vel_w
}
```

该函数全部用torch tensors，不能中途`.numpy()`、`.item()`或整体detach，才能保持guidance梯度。6D恢复和预测yaw提取需要数值稳定；接近奇异姿态的yaw选取规则记录，对cartwheel等动作实测，不能假设永无pitch90°。

cost分别接收物理world或指定current-yaw目标，由goal schema显式定义，不能隐式按上一tickyaw旋转。SDF地图坐标是world，使用body world position。

SDF relaxed barrier：

```text
if clearance >= delta:
    B = -log(clearance)
    dB/dclearance = -1/clearance
else:
    B = -log(delta) + .5 * (((clearance-2*delta)/delta)^2 - 1)
    dB/dclearance = (clearance-2*delta)/delta^2
```

delta>0，两段value和derivative在delta接续；batch计算使用安全分支或clamped log防止torch.where未选中分支仍产生NaN。finite-difference测试涵盖负clearance、接缝、远场。

## 5. 最小纯算法验证

1. 两种维度明确的random state/z，kstate!=kz，验证q_sample系数不是同一广播值。
2. perfect x0 oracle，DDPM final应恢复x0（已知history完全不漂移）；DDIM和DDPM在eta/随机seed相应规则下对比。
3. k0完全clean、k20接近噪声、coefficient无NaN、k1末端无额外随机。
4. 身体在匀速v1m/s轨迹上，root v_rel当前0，decode后velocity仍1；速度goal1的cost接近0、goal0的cost>0。
5. guidance toy joint model使state依赖latent，cost负梯度应改变latent/decoder动作；再用trained real model检查该关联。
6. known_mask硬约束、future partial keyframe、startup valid mask都独立测试；guided sampling不能改动clamped past/current。
7. mini optimization accumulation15与等量大batch的更新比较；DDP4卡梯度平均与global512定义一致。

这些数值验证通过后，仍必须做G3/G4真实物理测试。

## 6. checkpoint与策略接口

VAE checkpoint最少：model_config/state_dict、encoder/proprio normalizers、KL reduction、joint/body/action contract hashes、teacher map hash、data shard index hash、optimizer/RNG/step、latent convention。

diffusion checkpoint最少：model与EMA states、noise coefficients/clean convention、state/latent normalizers、P/P_pinv、body/joint名称、window schema/masks、VAE decoder hash、projection choices、optimizer/scheduler/RNG/epoch/global_update、train split与sampler配置。

纯policy接口：

```python
policy.reset(env_ids)
policy.act(actual_history, actual_proprio, task_goal, optional_keyframes)
```

输出action与diagnostics，禁止输入reference_motion/teacher/phase。physics env推进完再用`observe_transition`更新actual state与executed z/action histories；部分envreset分别清理。

加载时强校验decoder hash匹配diffusion latent数据，fp32/AMP转换不改变特征意义。错误schema默认fail-fast，不加静默pad/truncate维度“兼容”。
