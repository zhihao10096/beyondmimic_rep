## 2. v1 与 v4 必须分开

| 问题 | v1 描述 | 本次 v4 主线 |
|---|---|---|
| diffusion 对象 | 状态与直接动作 | 状态与 VAE 潜动作 |
| VAE + DAgger | 不作为后期潜扩散链路完整描述 | 明确包含条件 VAE、DAgger、VAE rollout |
| backbone | Transformer decoder、4 heads 的描述 | Transformer **Encoder**、8 heads，6层，512维 |
| 扩散链路控制频率 | 不采用早期隐含配置作本项目标准 | teacher 与控制在扩散链路用 **25Hz** |
| 未来窗口 | 早期 action horizon loss masking | 本项目采用 v4 的 H=16，不继承 v1 的 8 步动作损失屏蔽 |
| 数据扰动 | 早期有 delay randomization 的描述 | v4 补充给出 OU 动作噪声；不把 delay randomization 当 v4 必需默认 |

本次重点核实 P4 的“LDMs for Trajectory Modeling”、S3 状态/采集/代价、S4 实现、Tables S6/S7。v4 足够支撑明确的实现设计，但 noise schedule、若干归一化/采样细节等仍需工程决策。

## 4. R1 候选代码：值得复用但需要校准

目录前缀：`references/repos/BeyondMimic-Reproduction/`。

| 模块 | 审查结论 | 处理决定 |
|---|---|---|
| `stage2/models/conditional_action_vae.py` | 正确区分reference encoder和proprio decoder；实现mu/logvar、reparameterization、KL | 参考网络结构；重新统一输入和KL reduction |
| `stage2/dagger/collector_core.py` | student执行、teacher仅作监督标注的核心顺序正确 | 可参考；用真正Isaac状态和reset规则接入 |
| `adapters/isaac/live_rollout.py` | 包含真正student/VAERollout/diffusion闭环路径 | 超长耦合文件，应拆出可测试adapter；不可整体复制 |
| `stage3/representation/emphasis_projection.py` | 投影与伪逆持久化 | 可参考；64随机行是该仓库选择，不是论文明确数字 |
| `stage3/models/state_latent_transformer.py` | 逐token两类noise embedding，Encoder backbone | 可参考；补显式clean step、mask训练、一致sampler |
| `stage3/diffusion/training_runtime.py` | 实际训练路径使用cosine日程和x0目标 | 可以审阅；不代表训练效果已通过验证 |
| `stage3/diffusion/sampler.py` | 有单步probe和DDIM形式多步采样两条路径 | 不把单步probe称为论文采样；明确DDPM主线/DDIM消融 |
| `scripts/09_isaac/*` | 多种真实采集和评估入口 | 去掉 `/dev/shm/...` 作者Kit默认路径和USD缓存依赖 |

### 已核实的具体问题

1. **关节位置契约不一致。** `configs/stage2/vae_paper.yaml` 与 `PaperVAEConfig` 声明 `relative_to_default`，但 `live_rollout.py:_build_vae_tensors` 使用 `data.joint_pos`，未减默认位姿。若整个路径都绝对输入，可能内部仍可训练，但 metadata 错误，会导致迁移/新推理入口失败。不能仅改标签而不检查已有权重。
2. **anchor误差与官方坐标不同。** `_build_vae_tensors` 直接世界系相减、用 `q_ref*q_robot^-1`；官方使用机器人anchor系的frame transform。两种输入不能混入同一个normalizer/模型；本项目选择官方定义，需重建数据。
3. **Rot6D序列不同。** R1 `state.py:matrix_to_rot6d_array` 是两列分别拼接；官方tracking使用前两列矩阵按行flatten。各自可以正确，但不能共用不匹配的逆变换或teacher权重输入。
4. **mirror状态后复制latent。** `scripts/05_state_latent/build_motion_phase_symmetric_state_latent_dataset.py:60` 使用 `mirrored_latents=latents.copy()`；一般条件VAE并不保证镜像前后z不变。必须镜像reference后重新encode或采集镜像VAE轨迹，并验证decoder的动作相容性。
5. **k=0不代表完全干净。** R1 cosine schedule返回20个数组条目，首项alpha_bar≈0.992；clean mask虽强制覆盖输入，但noise embedding仍将其标为一个轻微噪声级。需独立设计明确的clean level，避免训练/推理语义混乱。
6. **备用linear schedule的终点不适合直接从纯噪声起步。** 本次数值探测：20步、beta 1e-4→0.02 的alpha_bar终点≈0.816777，保留信号系数≈0.903757。R1真实训练使用cosine，不能把这个问题描述成它当前默认训练必然失败；它是复用备用实现时的危险点。
7. **评估环境仍绑定tracking。** `_make_env` 仍要求motion文件；部分路径可移除reference terminations，但MotionCommand仍需核实是否会在末尾重置机器人。stage3最终验收应换成独立环境并做reference反泄漏检查。
8. **快速开始是合成/转换路径。** README里的 `collect_teacher_rollout.py` 基于 `rollout/from_motion.py` 生成转换样本，不等同teacher真实交互。真实入口必须从 `scripts/09_isaac/` 审查后选择。

这些是静态证据和有限离线探测；没有运行 R1 的训练或完整Isaac闭环。权重/结果目录未发现足以验证论文级复现的已训练产物，不能据此推断作者私有实验是否成功。

## 5. R2 UniPhys 的价值和边界

README提供预训练模型下载、数据集、训练及多任务闭环入口，证据比只有网络类更完整。关键参考文件：

- `uniphys/algorithms/diffusion_forcing/models/diffusion.py`：per-token加噪、x0/epsilon转换、sampling与guidance。
- `uniphys/algorithms/diffusion_forcing/models/transformer.py`：时序建模。
- `df_humanoid_steer.py`、`df_humanoid_goal.py`、`df_humanoid_obstacle.py`：从预测状态反归一化、恢复物理坐标、算任务cost的完整上下文。
- `uniphys/datasets/humanoid/babel.py`：离线轨迹取样和数据工程。

UniPhys是SMPL humanoid、Isaac Gym、另一个VAE/数据表示/方法体系。本项目不直接迁移它的权重或人体state-action数据，不引入其文本任务，也不照搬frame/clip/SNR权重。这里只复用经核对的数学和工程思想，保持 P4 语义。
