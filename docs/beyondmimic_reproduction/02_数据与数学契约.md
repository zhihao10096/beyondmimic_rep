# 数据、接口与数学契约

版本：设计契约 v1，2026-10-01。以下是本项目的确定实现方案。`P` 表示v4明确内容，`E` 表示为补齐复现所选的工程规则。修改任何契约都要提升schema版本并重建受影响数据，不能只修推理端。

## 1. 统一时间与机器人

- 机器人：官方G1 29DoF，模型和阻抗来自当前 `robots/g1.py`。运行时读取真实joint_names，不按CSV索引猜关节顺序。
- tracking anchor：`torso_link`；diffusion root：实际浮动根/`pelvis`，明确与IMU安装位姿之间的关系。二者不能互换。
- 控制25Hz：`control_dt=.04s`；原有物理步长`.005s`，decimation8。teacher使用 `Tracking-Flat-G1-Low-Freq-v0`。
- CSV30Hz转换为NPZ25Hz。MotionCommand每控制步推进一帧，因此必须断言 `motion.fps==1/control_dt`。50Hz调试支线需要单独teacher/数据/模型，不能与主线混合。
- `s_t`为执行当前动作前的物理状态；`z_t`经decoder产生`a_t`；`step(a_t)`后得到`s_{t+1}`。同一行保存`s_t,z_t,a_t`及该步的transition结果。不要在记录时把step后状态命名为`s_t`。
- 历史N=4：4个过去控制时刻，另有当前时刻；未来H=16：16个将来时刻。序列21帧，current_index4；历史`.16s`、未来`.64s`，整段首尾相差`.80s`。

目标身体先沿用官方tracking的14个：pelvis、left_hip_roll_link、left_knee_link、left_ankle_roll_link、right_hip_roll_link、right_knee_link、right_ankle_roll_link、torso_link、left_shoulder_roll_link、left_elbow_link、left_wrist_yaw_link、right_shoulder_roll_link、right_elbow_link、right_wrist_yaw_link。避障碰撞球可细化身体集合；该细化是独立schema，不隐式改变训练state维度。

## 2. 坐标、姿态和单位

世界系Z向上；米、秒、rad、m/s、rad/s。CSV root quaternion是`xyzw`，Isaac原生四元数为`wxyz`；内部raw schema默认`wxyz`，所有转换入口显式指定。归一化四元数、拒绝零范数；计算角速度前处理q与-q等价及符号连续性。

**Rot6D选定项目内部格式：旋转矩阵前两列的3×2子矩阵，按行flatten。** 即 `[R00,R01,R10,R11,R20,R21]`，与官方tracking一致。identity是 `[1,0,0,1,0,0]`。从6维恢复时先reshape3×2，再对两列Gram–Schmidt；叉积得到第三列。不要把该数组直接交给把前3元素当第一列的converter。

R1采用另一种两列拼接格式。复用时必须显式适配，不存在“同为Rot6D所以自动兼容”。若决定diffusion单独用列拼接，也可以，但必须另立schema/测试并记录转换；本计划不这样做。

空间坐标必须分清：reference world、robot root body、robot torso anchor body、当前character-yaw frame、逐帧character-yaw frame。不可把world误差和body误差当同一特征。

必须核对Isaac所取pos/velocity是否同属link origin或COM。存在COM/root/IMU偏置时，线速度按 `v_link=v_com+omega×(p_link-p_com)` 转到与位置同一物理点；在adapter中一次完成，并保存root定义。不要为方便混用root_link位置和COM速度。

## 3. teacher动作契约

```text
a_normalized: [B,29]，未乘scale的policy输出
q_target = q_default_runtime + action_scale * a_normalized
```

`q_default_runtime`应与当前domain随机化后的默认位姿一致；保存nominal与runtime值供审查。`action_scale`、stiffness、damping、armature、effort_limit均按运行时joint_names排列，包含hash。

teacher标签选择确定性的actor mean，经teacher原始observation normalizer，只归一化一次；freeze teacher、eval模式并禁止normalizer继续更新。`.pt`中加载actor+normalizer+原agent/env参数，不能只加载state_dict一部分。

动作监督比较normalized action，不能比较参考joint q、经过PD变换的q_target或实际关节位置。不要增加tanh或把PD target按机械关节范围clip；若wrapper有clip_actions，必须记录并区分proposed/processed/executed，默认保持官方逻辑。

teacher观测160维，仅针对本项目完整状态估计任务：`[ref_q29,ref_qd29,anchor_pos_error3,anchor_ori6,base_v3,base_w3,q_rel29,qd_rel29,a_last29]`。Wo-State-Estimation版本为另一schema（少6维），不复用其权重到完整版本。

VAE encoder67维、decoder96维不能硬截teacher160向量拼出来；用有名称的观测函数构建并与teacher入口核验。

## 4. 条件 VAE 输入与损失

| 输入 | 固定顺序 | 维度 |
|---|---|---|
| encoder reference | ref joint positions，ref joint velocities，anchor position error，anchor orientation error Rot6D | 29+29+3+6=67 |
| decoder proprio | projected gravity，root linear velocity body，root angular velocity body，joint positions relative to runtime default，joint velocities relative to default，previous applied normalized action | 3+3+3+29+29+29=96 |
| posterior | mu，logvar | 各32 |
| decoder output | normalized action | 29 |

`decoder_input_dim=96`若出现在设计描述中，指proprio部分；decoder MLP实际接收`concat(z32, proprio96)`，首层输入128。实现配置应采用`proprio_input_dim`与`decoder_total_input_dim`两个明确名称。

reference joint q保持MotionLoader绝对参考q；当前joint q用 `mdp.joint_pos_rel`，qd用官方`joint_vel_rel`。anchor error复用 `motion_anchor_pos_b`、`motion_anchor_ori_b`：位置为机器人anchor frame下的参考位置；旋转为 `R_robot_anchor^T R_ref_anchor`，不是世界系的左乘误差。

projected gravity：`R_root^T[0,0,-1]`。速度用root完整body rotation，而不是yaw-only rotation。

encoder不接受当前实际q、teacher action或teacher identity；decoder不接受任何reference/phase/teacher信息。训练时encoder可以看reference，stage3部署时完全不用encoder。

架构P：encoder/decoder hidden `[2048,1024,512]`，ELU，latent32，beta`.01`，LR`5e-4`，gradient accumulation15。

```text
q(z|ref)=N(mu,diag(exp(logvar)))
z=mu+exp(.5*logvar)*epsilon
a_hat=decoder(z,proprio)
L_rec=mean_batch(mean_joint((a_hat-a_teacher)^2))
L_KL=mean_batch(sum_latent(.5*(mu^2+exp(logvar)-1-logvar)))
L=L_rec+.01*L_KL
```

KL数学定义是逐维求和；论文没有说明数值reduction，**本项目先采用上述明确规则E**，并记录R1默认`mean_latent`会把有效KL权重减少32倍。提供该reduction消融，必要时比较归一化后的beta；不要只看“beta同为0.01”就称与原实现一致。

optimizer先AdamW，VAE weight_decay0（E），microbatch按机器可用显存设置，论文未给VAE batch/epoch数。loss/15后backward，每15个microbatch更新；尾批不足时按实际累积数修正。KL/logvar/normalizer在fp32，gradient clip1.0作为E保护并报告触发次数。beta warmup默认关闭；如启用要列为额外实验。

VAE输入normalizer：先从D0只用train partition估计，冻结；DAgger新增数据不静默变更。输出仍是原normalized action。初期不归一化action label；如以后改变则checkpoint记录逆变换。

posterior训练采样；VAERollout主线先用mu确定性rollout（E），执行与保存相同z。保留posterior-sample采集/评估消融；不能保存mu却用sample执行，或用执行后的动作反推未经训练的latent。

## 5. DAgger 的真实数据流

初始D0：teacher执行真实仿真动作，采集encoder/proprio/teacher label。BC warmstart后，D1起由student执行。

```text
for each control tick:
    snapshot = actual robot state before action
    reference = reference at the same current phase
    a_teacher = selected_teacher(snapshot, reference, actual_previous_action)
    z_student, a_student = VAE(reference, snapshot, actual_previous_action)
    save(snapshot, reference, a_teacher, z_student, a_student)
    apply(a_student)       # a_teacher仅为监督标签
    next_state, done_reason = physics_step()
    finalize transition; segment if reset/motion discontinuity occurs
```

teacher查询的是student实际状态；不能开一个独立teacher环境，在其自身轨迹上获取标签。teacher看到的a_last是student/扰动实际执行的前一动作。

多teacher首版按motion分批启动采集，避免侵入MotionCommand多文件管理。teacher map关联motion_id、checkpoint、normalizer、env/task、NPZ及metadata。每段仍用对应teacher。后续如并行env分配多motion，必须按env_id路由并独立保存previous_action、episode_id和phase。

可用短暂teacher/student执行混合进行warmstart（E），但是每条记录必须有executed_policy和mix_probability；正式DAgger评估必须student-only。不把teacher接管后的片段作为student能力证据。

聚合建议D0+历轮DAgger、按motion与phase平衡；旧数据至少25%作为初始E，以实验确定。验证按完整rollout/run分割，不能随机拆同一窗口的邻帧。

## 6. raw rollout schema 与文件组织

采用HDF5或分块NPZ+JSON sidecar（最终只选一种主存储）；禁止每个长实验一次把所有GPU数据堆进内存。dataset_index记录shard、episode、motion和分区。路径相对data_root，支持服务器迁移。

每条raw timestep最少包含：

| 字段 | Shape | 语义 |
|---|---|---|
| episode_id, env_id, motion_id, teacher_id | scalar/string | 可追溯、不可跨reset |
| control_step, time_s, reference_frame | scalar | 时间关系和相位 |
| root_pos_w, root_quat_w | 3,4 | actual，quat wxyz |
| root_lin_vel_w, root_ang_vel_w | 3,3 | 与root物理点一致 |
| body_pos_w, body_lin_vel_w | Jb×3 | actual、按body_names |
| joint_pos, joint_vel | 29,29 | raw actual；用于decoder/对称性 |
| default_joint_pos_runtime, previous_action | 29,29 | 默认值和前一执行动作 |
| encoder_input, decoder_input | 67,96 | Stage2和采集期可存；Stage3网络不能读取encoder |
| teacher_label, vae_action_clean, action_executed | 29各 | 按采集类型可选，不能混同 |
| mu, logvar, latent_used | 32各 | latent_used为实际解码的z |
| ou_noise | 29 | 扰动采集单独存 |
| terminated, truncated, reset, command_resampled | bool | 每项分别保存 |
| termination_reason, next_episode_id | scalar | 真实故障与边界 |

meta：schema_version、seed、collector类型、git commits、model与asset SHA256、频率、名称/坐标/单位、normalizer、noise配置、joint/action映射、accepted条件、collect_start_phase、数据分区来源。拒绝匿名二维数组无语义meta。

MotionCommand内部到末尾重采样可能不产生env done。必须比较phase连续性、command_resampled及episode ID；一次内部write_root_state也属于数据边界。terminated步可以保留pre-action状态做诊断；用于轨迹训练则不得包括reset后的next_state。

## 7. 第三阶段 VAE + OU 数据采集

P：对VAE输出加动作噪声；theta`.8`、mu0、sigma`.1`、OU dt1.0（按每个控制tick的离散系数，**不是`.04s`**）。

```text
eta_next = eta + .8*(0-eta)*1.0 + .1*sqrt(1.0)*epsilon
a_executed = a_clean + eta_next
```

实际轨迹保存 `s_t,latent_used_t`，z是干净VAE潜变量；额外记录a_clean、a_executed、OU。下步decoder的a_last是a_executed。OU按env/episode清零。

P：记录约2.5s的数据，但至少让motion继续到5s以验收稳定性；5s内失败则整段前缀也拒绝。25Hz下2.5s不是整数步，E采用63个控制transition=2.52s，5s为125步，meta记录确切步数。为每个reference frame力求约100次覆盖；被拒绝样本另存失败索引统计，不能丢掉其比例。

收集期间保留官方targeted domain randomization。先做clean/OU小样本基线，再扩大；是否在5s验证尾段继续OU本项目默认继续（E），另行记录。不要把参考FK或teacher动作替换成该VAE闭环轨迹。

## 8. 混合 character–yaw 状态表示

P：当前时刻t的frame由root位置p_t、root yaw旋转Y_t定义。每窗口重新锚定，不能把上一窗口的已变换history token直接复用。

对n∈[-4,16]：

```text
p_rel[n] = Y_t^T (p[t+n]-p[t])
R_rel[n] = Y_t^T R[t+n]
v_rel[n] = Y_t^T (v[t+n]-v[t])
w_rel[n] = Y_t^T w[t+n]
body_p_local[n,b] = Y_[t+n]^T (body_p[t+n,b]-p[t+n])
body_v_local[n,b] = Y_[t+n]^T (body_v[t+n,b]-v[t+n])
```

s=`[p_rel3,Rot6D(R_rel)6,v_rel3,w_rel3,body_p_local(3Jb),body_v_local(3Jb)]`，Ds=`15+6Jb`；14 bodies→99。这个99维是本项目选定body集合/姿态格式的结果，不声称论文逐维公开了99。

当前root相对pos/linear vel必为0。**v_rel是速度差，不是绝对速度！** cost与评估要恢复 `v_world[n]=Y_t*v_rel[n]+v_world[t]`。如果忘加v_t，机器人匀速向前时可能被guidance误判为静止。保存context p_t、Y_t、v_t用于恢复，不送给模型任何future reference。

恢复body world position：`p_world[n]+Y_[t+n]*body_p_local[n,b]`，其中Y_[t+n]从预测R_rel恢复world orientation后提取yaw。body velocity同理加预测root velocity。

S3公式和正文“root frame”用语不完全一致；本项目以补充公式的yaw-only frame与减v_t为准（E裁决，见决策文件）。当前root绝对高度并未作为独立特征，采用body-local几何与最新proprio；同时保留raw height用于评估，不能向state偷偷插入高度再称原schema。

## 9. emphasis projection 与归一化

P：root pose/twist的emphasis coefficient c6；随机Gaussian投影与identity拼接，伪逆恢复。投影行数未明确公开。

E主线：`A[M,Ds]~N(0,1)`，`M=64`；`B[Ds,Ds]`为对角矩阵，root前15维=6，其余=1；`P=concat_rows(A@B,I_Ds)`；s'=P@s。P伪逆一次计算保存；random seed固定7。**R1使用root-only选择矩阵，与本选择不完全相同，作为投影消融而非直接称论文原实现。**

Ds99→projected163，拼z32后token195。先用train分区的raw hybrid state做逐维standardization，再P投影；latent单独train标准化（E）。优先不在P输出逐维重新标准化，否则可能抵消emphasis权重。保存`state_mean/std,latent_mean/std,P,P_pinv`到模型；其他归一化顺序只作为单独消融。

解码cost路径：projected预测→P_pinv→反state归一化→恢复world/root物理量。引导计算始终使用米/m/s/rad物理单位；gradient通过该可微链返回noisy token。z执行前反latent归一化，不能直接把标准化后的z给VAE decoder。

## 10. 窗口、mask与独立噪声

窗口中心t可用范围：同episode里t>=4且t+16有连续数据；accepted_episode整段为真；相邻time_s差`.04`，phase连续或显式未使用参考phase的真实episode；无command内部重置。

mask定义：

| 时刻 | state | latent |
|---|---|---|
| t-4..t-1 | 已观察，clamp历史实际state | 已执行的历史z，clamp |
| t | 当前实测state，clamp | **待生成；不能用VAE encoder读取reference填入** |
| t+1..t+16 | 生成，可按任务只clamp指定keyframe维度 | 生成 |

每个state和latent有独立noise index，形状k=`[B,21,2]`。本项目显式定义clean level0，`alpha_bar[0]=1`；noise level1..20；末端alpha_bar接近0。训练用逐token随机levels，包括clean条件情况，补一定比例与推理mask相同的训练样本（E），防止全部历史noise同时为0是未见条件。

inpainting只约束指定state维度，不强行指定未来latent或把整个姿态/速度token误锁住。观测mask、keyframe_mask、loss_mask分别保存，并给模型显式known-feature/valid-time mask条件（E）。部分state已知时不能把整个state noise level标0。默认loss预测全部21帧的x0，在生成项上按有效feature维数平均；clean observed项可置零监督，具体选择写入config，不能用N/H名掩盖目标。确切接口和reverse系数见09文件。

## 11. Transformer、训练和采样

P架构：TransformerEncoder，6层，8 heads，embedding512；N4/H16；x0目标；20 denoising steps。P训练：global batch512，epochs1000，LR1e-4、WD.001、cosine LR、warmup10000 **optimizer更新步**、EMA power.75/max.9999。

P未给FFN宽度、dropout、position encoding等。本项目E：FFN2048、GELU、dropout0、learned time position embedding、state/latent noise embeddings、非因果attention。输入为每时刻拼接state+latent；如改为交替42 tokens，要记录并做shape/性能比较。拟合联合分布不等于要求attention causal mask；不能引用论文“causal consistency”就加单向mask。

diffusion主线E：cosine alpha_bar，显式clean level；standard DDPM x0 posterior，多步逐级denoise20次，最后无额外noise。coefficients由alpha_bar导出，禁止把论文示意式里的同名alpha直接当原样代码。

DDIM deterministic20步作为可复验/加速对照，避免R1的DDIM实现默认为作者精确sampler。不得声称20训练levels等于用了1000训练levels+20次采样；这种替代必须写明。linear20步小beta日程不作为纯噪声初始化主线。

guidance：从预测x0物理轨迹计算G，再求 `dG/dx_k`，按负梯度更新。baseline采用posterior mean的covariance-scale score correction；记录每noise level权重和gradient norm。可提供“更新noisy输入后重算denoiser”的R1风格消融，不能混为一个算法。

必须允许guidance对latent产生影响（通过联合denoiser或后验score），不能只让预测state变好、latent保持不动。冻结模型weights但保持对input的autograd；`model.eval()`仍需要 `torch.enable_grad()` 的guidance路径。不把整个控制循环包在 `torch.inference_mode()` 下。

## 12. 任务代价与执行

- 速度：`.5*sum_future ||v_xy_physical-g_v||²`；另有yaw rate任务权重E，因为v4演示有yaw指令，但补充的速度式只显式给xy项。current项为已观测固定值，对优化无效可保留用于日志。
- 航点：`sum((1-exp(-2d))*||p_xy-goal||²+exp(-2d)*||v_xy||²)`。d的gradient是否detach在v4补充未明确，E默认detach该distance权重，使用v1清晰说明作理由；记录消融。stop目标是绝对velocity0，不是v_rel0。
- 避障：sum over future、body碰撞球的relaxed barrier `B(SDF(p_b)-r_b,delta)`；必须使用三维物理身体坐标，不能只看root二维轨迹。delta/radii工程选定并写meta。低于delta用二次延拓，避免log负数产生NaN。
- inpainting：未来稀疏state keyframe约束，插值生成latent+剩余state；0.2s相当5控制步。keyframe来自参考关键帧或已验证VAE轨迹并正确重锚定；不能把其对应teacher action灌入控制。
- composition：cost加权相加，允许velocity/waypoint/avoidance/inpainting模式切换。针对inpainting锁定的token，gradient不得破坏constraint。

每控制tick：重建actual history→clamp actual current state→sampling→提取current z→inverse latent normalizer→**使用最新实测proprio** decoder→PD execution。预测state只用于cost、可视化和诊断；下一tick历史state必须重新读物理系统，不能回写为预测。

第一版同步闭环。第二版async snapshot有时间戳，推理期间控制继续；生成结果按目标执行tick选相应future z，超龄计划丢弃。decoder每tick仍用最新proprio；记录planned_tick、executed_tick、plan_age、missed_deadline。warm-start shifting要重锚定旧预测，不能直接平移标准化token数组。

第三阶段policy API只允许`actual_history,actual_proprio,task_goal,optional_keyframes`。teacher/reference/motion_id只允许评估记录和初始reset取分布；后续行为不能依赖原始reference相位。独立环境不能按reference tracking error终止。
